# Setas de la Peña

> **Setas OS activo:** la implementación canónica está en `field-os-simulador/setas-os/` sobre la rama `main` de este repositorio. Antes de modificar Setas OS, consultar [`SETAS_OS_CANONICAL.md`](./SETAS_OS_CANONICAL.md) y `field-os-simulador/setas-os/setas-os.json`. Los repositorios `setasdlp-code/Field-OS` y `setasdlp-code/simulador` no son fuentes vigentes de la aplicación.

## Setas OS

La aplicación operativa de Setas OS se desarrolla actualmente en:

`field-os-simulador/setas-os/`

El shell principal es `Setas OS v5.dc.html`. El número incluido en el nombre del archivo es heredado y no debe utilizarse para escoger entre copias. La referencia de estado actual es siempre `main` más el manifiesto `setas-os.json`.

La aplicación actual incluye, entre otros componentes, formulación de sustratos, bodega e inventario, producción, bitácora, pruebas, integración Firebase y autenticación. Para reglas de canonicidad, ramas y migración futura, consultar [`SETAS_OS_CANONICAL.md`](./SETAS_OS_CANONICAL.md).

## Repositorios históricos

`setasdlp-code/Field-OS` conserva un prototipo navegable anterior. `setasdlp-code/simulador` conserva material histórico adicional. Pueden consultarse para comparación o recuperación deliberada de funciones, pero no deben recibir nuevas funciones o correcciones de Setas OS.
