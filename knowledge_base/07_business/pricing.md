# Estado

*Lentinula edodes* es el producto inicial previsto. No existe una lista de precios activa porque el proyecto tiene 0 lotes, costo por kg desconocido, vida útil sin validar y compradores todavía no confirmados.

Las tablas anteriores de *P. djamor* se retiran del programa comercial activo. Esa especie puede modelarse en una fase futura mediante una decisión separada.

# Principios

- No publicar precio antes de conocer costo por kg vendible y condición de entrega.
- No usar precios de producto importado como sustituto del precio aceptado por compradores locales.
- Separar precio de lista, precio neto cobrado, descuento, logística e impuestos.
- Definir grados comerciales con compradores y con `06_operations/quality_control.md`.
- No comprometer frecuencia ni volumen antes de validar ciclos.

# Investigación de precio

Registrar por comprador:

| Campo | Registro |
|---|---|
| Canal | Restaurante, tienda especializada, D2C u otro |
| Producto | Shiitake fresco, grado y presentación |
| Volumen | kg por entrega y frecuencia |
| Precio observado | COP/kg, fecha y condición |
| Pago | Contra entrega, días de cartera, factura |
| Logística | Quién entrega y costo |
| Calidad | Tamaño, apertura, corte, empaque, vida útil |
| Sustituto | Producto local/importado con el que compara |
| Decisión | Interés, muestra, prueba, rechazo y motivo |

# Formación del precio

```
precio mínimo provisional
  = costo variable por kg vendible
  + logística por kg
  + merma esperada
  + margen de contribución aprobado
```

El precio definitivo se aprueba después de:

1. cerrar el lote piloto;
2. validar la clasificación del producto;
3. medir merma y vida útil;
4. obtener evidencia de al menos varios compradores objetivo;
5. confirmar requisitos de empaque y facturación.

# Grados

Los nombres Premium y Estándar son provisionales. No se usan diámetros, colores o porcentajes heredados de *P. djamor*. Cada grado debe describir condición, integridad, madurez de cosecha y tolerancias acordadas para shiitake.

# Prohibiciones

- No vender material sin trazabilidad o liberación de calidad.
- No convertir producto descartado en grado comercial.
- No prometer claims medicinales.
- No fijar descuentos permanentes antes de conocer el margen.
- No extrapolar precios deshidratados o extractos al programa de fresco.
