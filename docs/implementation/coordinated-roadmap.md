# Hoja de ruta coordinada: operación y página pública

Prioridad confirmada: piloto y UX diaria en Setas OS; portada reducida y utilidad culinaria en la web. Planes: [Setas OS](setas-os-implementation-plan.md) y [página pública](public-implementation-plan.md).

Orden: WEB0 (publicación trazable de portada) → OS0 (verificar situación real) → OS1/OS2 (turno y preparación) → WEB1/WEB2 (acciones y fichas) → OS3/OS4 (insumos y captura) → OS5/OS6 (recuperación y aceptación) → WEB3–WEB6. Priorizar fallos críticos operativos sobre mejoras editoriales.

Un lead; una rama por paquete. Trabajos paralelos solo con archivos disjuntos. Añadir revisión independiente en sincronización, datos o permisos; un agente basta para edición editorial acotada. La investigación, los planes y el código se entregan por separado.

La web no depende de completar Setas OS para existir. La activación de venta depende de oferta y logística reales aprobadas, no de una fecha del roadmap. Setas OS no necesita publicar datos para operar.

Estimaciones: Setas OS 27–51 h iniciales; web conserva envolvente previa 44–79 h y se reestima al identificar la publicación. No son compromisos ni se suman con otros backlogs. Antes de cada paquete revisar main y evidencia: los planes históricos no son lista vigente de defectos.
